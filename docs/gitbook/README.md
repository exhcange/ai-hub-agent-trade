# AI Hub

Use AI Hub for spot and Futures market data, account queries and separately confirmed trading through CLI, MCP and Skills.

This guide is for first-time users with npm already installed. Start by installing the AI Hub packages, create spot and futures profiles, connect your MCP client, and install both sets of Skills.
